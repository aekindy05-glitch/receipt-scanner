สแกนใบเสร็จ PDF → สรุป Excel รายวัน

อัปโหลดไฟล์ใบเสร็จ/ใบกำกับภาษี (PDF) ให้ Gemini อ่านและแยกข้อมูลให้อัตโนมัติ ตรวจทานแล้วค่อย Export เป็น Excel

1. ตั้งค่า

API Key ใช้เชื่อมต่อ Gemini โดยตรงจากเบราว์เซอร์ของคุณเท่านั้น ไม่ถูกส่งไปเก็บที่เซิร์ฟเวอร์ไหน — ถ้าไม่ติ๊ก "จำ API key" จะหายไปเมื่อปิดหน้านี้ ถ้าติ๊กไว้จะถูกเก็บไว้เฉพาะในเบราว์เซอร์เครื่องนี้เท่านั้น (localStorage) ไม่ควรติ๊กถ้าใช้เครื่องสาธารณะ/เครื่องที่มีคนอื่นใช้ร่วม

2. อัปโหลดไฟล์ใบเสร็จ (PDF)

ลากไฟล์ PDF มาวางตรงนี้ หรือคลิกเพื่อเลือกไฟล์
รองรับหลายไฟล์พร้อมกัน (เช่น ใบเสร็จ 20 ใบต่อวัน)

3. ตรวจทานข้อมูล ก่อน Export

ยังไม่มีข้อมูล — อัปโหลดและประมวลผลไฟล์ก่อน

⚠ ช่อง "ประเภทการรับเงิน" (เงินสด/โอน/บัตร/เช็ค) ไม่มีอยู่ใน PDF ต้องเลือกเองให้ตรงกับที่ได้รับจริง ก่อน Export
